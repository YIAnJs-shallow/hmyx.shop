# 本地域名配置说明：浏览器输入「惠蒙优选」直接打开商城

配置完成后，在本机浏览器地址栏输入 **惠蒙优选** 并回车，即可像访问普通网站一样
打开惠蒙选落优地页（welcome.php），不再需要输入 `localhost/my_project` 这样的路径。

原理：浏览器会把中文域名「惠蒙优选」自动转换成域名编码
`xn--4oq564b47zxtj`，我们通过 hosts 文件把这个编码指向本机（127.0.0.1），
再让 Apache 把这个域名的站点根目录指向本项目。

## 配置步骤（只需做一次）

### 第 1 步：安装 Apache 虚拟主机配置

把本项目目录下的 `deploy/huimeng_vhost.conf` 复制到：

```
E:\e2\phpstudy\phpstudy_pro\Extensions\Apache2.4.39\conf\vhosts\
```

（vhosts 目录里已有 `0localhost_80.conf` 等文件，放在一起即可）

### 第 2 步：修改 hosts 文件（需要管理员权限）

1. 在开始菜单搜索「记事本」，右键选择 **以管理员身份运行**
2. 记事本中打开文件：`C:\Windows\System32\drivers\etc\hosts`
   （文件类型选「所有文件」才能看到）
3. 在文件末尾追加两行并保存：

```
127.0.0.1 xn--4oq564b47zxtj
127.0.0.1 www.xn--4oq564b47zxtj
```

### 第 3 步：重启 Apache

打开 phpStudy（小皮）面板，停止再启动 Apache。

### 第 4 步：验证

浏览器地址栏输入 **惠蒙优选** 回车 → 应看到惠蒙优选新人落地页。
输入 `惠蒙优选/index.php` 则直接进入商城列表页。

## 常见问题

- **输入中文后变成了搜索结果？** 部分浏览器会优先按搜索处理，此时在中文后面
  加一个 `/` 再回车（如 `惠蒙优选/`），或直接输入 `xn--4oq564b47zxtj` 验证。
- **改了 hosts 不生效？** 命令行执行 `ipconfig /flushdns` 刷新 DNS 缓存。
- **想改回原样？** 删除 vhosts 目录里的 `1huimeng_80.conf`（复制过去的文件）
  并删掉 hosts 里追加的两行，重启 Apache 即可。

## 重要说明

此配置**仅对本机生效**。「惠蒙优选」这个名字要让互联网上的任何人都能访问，
需要：购买正式域名（国内还需 ICP 备案）+ 部署到公网服务器。本地开发阶段用
上述方案即可获得与正式网站一致的访问体验。
